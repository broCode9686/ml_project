# TeleChurn — Customer Churn Prediction

## Overview

TeleChurn is a machine learning project that predicts whether a telecom customer is likely to **churn within the next 30 days**.

The project uses customer demographics, services, account information, and usage-related features to identify customers at high risk of leaving.

## Objective

- Predict customers likely to churn
- Identify factors contributing to churn
- Evaluate models using **ROC-AUC and Lift Score**
- Connect predictions to **customer retention strategies**

## Dataset

**IBM Telco Customer Churn Dataset**

The dataset contains customer information including:

- Demographics
- Services subscribed
- Contract and payment details
- Tenure and billing information
- Customer churn status
